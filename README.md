## Бот для продаж и рекламы

## Структура бота
main.py - вся логика бота
keyboards.py - кнопки
db.py - для работы с SQLite
states.py - для FSM-состояний
.env.example - для токенов и айди

## Возможности
Собирает краткую информацию о бизнесе клиента и уведомляет админа/менеджера, которые те получают структуированные заявки в том же боте. Сохраняет все заявки в SQLite, логирование действий

## Как настроить
Клонируйте репозиторий - git clone https://github.com/Error623/BotBusiness.git
У себя создайте .env по примеру .env.example. в BOT_TOKEN вставьте токен вашего бота (Узнавать у @BotFather)
В ADMIN_IDS добавьте айди аккаунтов ваших менеджеров, чтобы им приходили заявки (Узнавать у @userinfo3bot)
Установите зависимости - pip install -r requirements.txt
Запуск - Python main.py
